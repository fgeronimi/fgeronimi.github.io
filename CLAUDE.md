## Ce qu'est ce projet

Site personnel statique (`fgeronimi.github.io`), servi tel quel par GitHub
Pages : pas de build, pas de framework, pas de dépendances.

- `index.html` — page d'accueil (liste des projets).
- `project/*.html` — pages dédiées à certains projets (ex. `rorshark.html`).
- `img/` — assets statiques.

## Règles d'or

- HTML/CSS en ligne, pas de framework ni d'étape de build à introduire.
- Rester minimal : pas de dépendances, pas d'outillage (bundler, linter, CI)
  non demandé explicitement.
- Contenu en français.

## Git & commits

- Ne committer/pusher que quand demandé explicitement.
